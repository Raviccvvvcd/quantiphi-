# AI Chat Assistant (Quantiphi Vibe Coding)
- **Frontend:** Streamlit chat bubbles, real-time character streaming, history sidebar, Tone Toggle (`Professional`, `Casual`, `Concise`).
- **Backend:** FastAPI + OpenAI API + MongoDB persistence (`timestamp`, `user`, `ai`, `tone`).
- **2 Extra Features:** (1) One-click Markdown chat export, (2) Quick prompt starters + response latency telemetry.
